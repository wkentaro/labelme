Fixed the app crashing when saving a label file failed on a raw filesystem error rather than a wrapped `LabelFileError`; `save_labels` created the output directory (`Path.mkdir`) and computed the image's relative path inside its `try` but caught only `LabelFileError`, so a read-only or full `--output` directory (`PermissionError`/`OSError`) or another raw `ValueError` escaped uncaught and took the whole app down through the global exception hook, including during auto-save. These are now caught like the existing write failures, surfacing the save-error dialog and returning `False`
