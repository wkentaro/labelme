AI-Points and AI-Box merge into AI-Segment, which segments one object from any mix of clicked points, Shift-clicked negative points and one dragged box, with every model including SAM3. It targets one object; SAM3's box used to add every similar object, which AI-Find All's example box now does. A box is dragged instead of placed with two clicks: press Enter to finish it, or hold Ctrl while you drag to finish on release. Labelme requires osam 0.10.1 or later.
