AI-Points and AI-Box merge into AI-Segment, which segments one object from any mix of clicked points, Shift-clicked negative points and one dragged box, with every model including SAM3. It always returns one Shape; SAM3's box used to add every similar object, which AI-Find All's example box now does. A box no longer finishes on release: press Enter, or hold Ctrl while you drag. Labelme requires osam 0.10.1 or later.
