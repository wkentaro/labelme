Fixed labelme refusing to start (exiting with status 1 and `Config file does not exist`) when `~/.labelmerc` does not exist and could not be created, such as on a read-only or otherwise unwritable home directory; the auto-discovered config path was the default value of `--config`, so a missing one was treated like an explicitly requested file that is missing. A missing file is now fatal only when it was explicitly passed via `--config`, while a missing default path logs a warning and starts on the built-in default settings
