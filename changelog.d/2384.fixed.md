Fixed a startup crash when loading the config raised anything other than `ValueError`, such as a malformed `~/.labelmerc` or `--config` file with ungrammatical YAML (a `yaml` parser error); `MainWindow._load_config` caught only `ValueError`, so every other error crashed before the window opened. It now catches any such error, surfaces it in the configuration-error dialog (with an Ignore-and-use-defaults option), and falls back to defaults
