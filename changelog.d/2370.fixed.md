Fixed the configured `ai.default` model not being applied at startup when it resolves to the first list entry, i.e. when it is set to `EfficientSam (speed)` or to an unrecognized value (which falls back to that entry): the AI-Assisted Annotation panel only pushed its selection to the canvas on `currentIndexChanged`, which never fires for the already-selected index 0, so the panel showed the chosen model while the canvas silently kept the hardcoded `sam2:latest` until the model was toggled by hand. The canvas is now initialized from the panel's resolved selection (model and output format) instead of waiting for a change signal ([#2403](https://github.com/wkentaro/labelme/pull/2403))
