Fixed a startup crash (`OSError: [Errno 36] File name too long`) when a `--labels`, `--flags`, `--label-flags`, or `--config` value is longer than the filesystem's filename limit (reachable with a few dozen inline comma-separated labels); these options probe whether the value names an existing file via `Path(value).is_file()`, which raised instead of returning `False` on an over-length value, so the value is now treated as inline data as intended
