AI-Find All replaces the AI Text Prompt. It finds every object that matches a text prompt, or a box around one example that you refine with more examples and with counter-examples drawn while holding Shift, then add with Enter or discard with Esc. The whole prompt is one concept, so commas no longer split it. Each batch asks for one label, prefilled with the prompt, so "black dog" can be saved as "dog", and objects already annotated with the same Output and label are skipped.
