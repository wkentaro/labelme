Fixed a crash when a `label_flags` config entry contains a pattern that is not a usable regular expression, either an invalid one (e.g. `person-(`) or a non-string one (e.g. the unquoted numeric key in `2024: [occluded]`, which YAML parses as an int); such a pattern raised an uncaught `re.error` or `TypeError` when loading a labeled shape or typing in the label dialog, and is now skipped instead, with a warning logged naming the offending pattern
